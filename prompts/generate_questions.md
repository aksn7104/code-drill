# AI に問題集を作らせる指示文

このファイルは、**AI（Claude・ChatGPT など）に問題を作ってもらうための質問文**と、**作ってもらった問題を、このドリルに入れる手順**です。
AI は必須ではありません。同梱の見本（Python・SQL）だけでも使えます。自分の学びたい言語・単元を足したいときに使います。

## 全体の流れ（5分ほど）

1. 下の「指示文」を、AI のチャットに貼り付ける（5か所を書き換える）
2. AI が YAML を出力するので、全体をコピーする
3. `questions/{言語}/` のフォルダに、`u01_単元名.yaml` のような名前で保存する
4. `python drill.py --check` で、形式が正しいか確かめる
5. 言語を新しく足したときだけ、`config.yaml` の `languages` に言語名を書く

くわしい手順は、このファイルの下の「作った問題を、問題集に入れる手順」にあります。

## 書き換える5か所

| 場所 | 意味 | 例 |
|---|---|---|
| `{言語}` | 言語（`questions/` の下のフォルダ名。英小文字がおすすめ） | python、sql、javascript |
| `{単元}` | 学びたい内容 | 変数と四則演算、SELECT と WHERE |
| `{難易度}` | 1〜5 の整数（1が易しい） | 2 |
| `{問題数}` | 作ってほしい問題の数 | 4 |
| `{既習の内容}` | すでに学んだ文法・単元（箇条書き）。なければ「なし」 | 変数、print、足し算と引き算 |

`{既習の内容}` を書くと、AI は「すでに学んだことを組み合わせた問題」を作ってくれます。簡単すぎる問題が減ります。学習が進んだら、書き足してください。

## 指示文（ここから下を貼り付ける）

````text
あなたはプログラミングの先生です。次の条件で、練習問題を {問題数} 問、YAML で作ってください。

- 言語：{言語}
- 単元：{単元}
- 難易度：{難易度}（1〜5 の整数。1が易しい）
- すでに学んだ内容：{既習の内容}
- 題材：架空のデータ（個人情報・実在の会社や人物の情報は使わない）

## 形式（YAML のリスト。1問が1項目）

必須の項目は次の8つです。

- id：問題の番号。ほかの問題と重ならない文字列（例：py-var-001）
- unit：その問題で学ぶ内容（短い見出し。答えは書かない）
- level：難易度（1〜5 の整数）
- type：blank（空欄を文字で答える）か choice（選択肢から選ぶ）
- question：問題文
- code：コード。答えを入れる場所は ___（アンダースコア3つ）にする。YAML の `|` を使う
- answer：答え。必ず引用符で囲む（例："+" や "10"。囲まないと YAML が別の型として読む）
- explanation：解説。なぜその答えになるのかを説明する

任意の項目：

- choices：type が choice のときだけ。選択肢のリスト（4つ。answer は、その中のどれか1つと同じ文字にする）
- hint：ヒント（答えそのものは書かない）

## 難易度の目安

- Lv1 読む：1行のコードの意味や結果を選ぶ
- Lv2 埋める：2〜3行のコードの空欄1か所を埋める
- Lv3 組み合わせる：空欄2か所、または、すでに学んだ文法と組み合わせる
- Lv4 間違いを探す：動かないコードの間違いを選ぶ・直す
- Lv5 実務寄り：小さな処理を完成させる。長めのデータ（20〜30行）から一部を読み解く問題を含む

## 守る決まり

1. 答えを、unit・question・code・hint に書かない。見出し（unit）や問題文に、答えになる命令や文法の名前（WHERE、for など）を書かない。問題文は、何をしたいかで書く
2. 同じ文法・同じ考え方を、2問続けて問わない。2問で同じ答えを問わない
3. 1問につき、答えが1つに決まるようにする（blank は、短い1語か記号にする）
4. コードは5行以内にする。1問に新しい文法は1つまで。そのまま動く正しいコードにする（空欄に answer を入れたとき）
5. 計算問題にしない。問うのは文法の意味だけ。数値は「10打数3安打」のように、暗算ですぐ分かる数にする
6. 難易度の下限：Lv1 は、その単元の最初の1問だけ。2問目以降は Lv2 以上にする。空欄は、考えないと入らないものにする。前の問題と同じ形の空欄を続けない
7. 選択肢（choice）は4つ。文法の意味を理解していないと迷う、紛らわしいものを1つ入れる（例：`/` と `//`）
8. 「すでに学んだ内容」は、学んだものとして扱い、基礎的すぎる問題にしない。すでに学んだ文法を1つ組み合わせる。すでに出した問題と、同じ内容・同じ型の問題は作らない
9. 解説は、答えの理由と、つまずきやすい点を書く。略語や命令は正式名称も書く（例：len = length）。基礎以外の補足（実務での使い方など）を1つ付ける
10. 送る前の見直し：作った問題を、出力する前に次の3つで確かめ、1つでも当てはまれば作り直す。(1) 問題の答えが同じ語・同じ文法になっている (2) 見出し・問題文・コードに、答えが出ている (3) コードを読まなくても、選ぶだけで正解できる
11. 出力は YAML だけにする（前置きや説明の文章は付けない）

## 出力の見本（この形で書く）

```yaml
- id: sample-001
  unit: 合計金額を求める（変数・足し算）
  level: 1
  type: choice
  question: 値段と送料から、支払う合計金額を求めます。空欄に入る記号はどれですか？
  code: |
    price = 1200
    shipping = 300
    total = price ___ shipping
    print(total)
  choices: ["+", "-", "*", "/"]
  answer: "+"
  explanation: |
    合計は「値段 + 送料」で求めるので、足し算の + が入ります。
    変数は「名前 = 値」で作り、あとから名前で呼び出せます。
  hint: 支払う金額は、値段と送料をあわせた数です。

- id: sample-002
  unit: 1個あたりの値段を求める（割り算）
  level: 2
  type: blank
  question: 合計金額と個数から、1個あたりの値段を求めます。空欄に入る記号を答えてください。
  code: |
    total = 900
    count = 3
    unit_price = total ___ count
    print(unit_price)
  answer: "/"
  explanation: |
    割り算は / です。結果は、割り切れなくても小数（float）で返ります。
  hint: 1個あたりは「合計 ÷ 個数」です。
```
````

## 作った問題を、問題集に入れる手順

### 1. 保存する

- AI が出力した YAML を、そのまま（前後の説明や ```yaml の行を除いて）ファイルに保存します
- 保存する場所：`questions/{言語}/` のフォルダの中。フォルダがなければ作ります（フォルダ名が言語の名前になります）
- ファイル名：単元ごとに1ファイル。`u01_variables.yaml`、`u02_loops.yaml` のように、**先頭に番号**を付けます。出題の順番は、このファイル名の順です
- 文字コードは UTF-8 で保存します（Windows のメモ帳なら「UTF-8」を選びます。VS Code は初期設定のままで大丈夫です）

### 2. 検査する

```
python drill.py --check
```

- 誤りがあれば、ファイル名と問題の番号つきで、まとめて表示されます
- 誤りの文章を、そのまま AI に貼って「直してください」と頼むと、直してくれます
- 検査に通らないまま起動しても、出題の前に同じ検査が行われ、誤りがあれば出題せずに止まります

### 3. 新しい言語のときだけ：設定を足す

- `questions/{言語}/_language.yaml` を作ります（採点のきまり。AI に作らせる指示文は `prompts/generate_language.md` です）
- `config.yaml` の `languages` に、言語名を足します（`config.yaml` は、`config.example.yaml` をコピーして作ります）

```yaml
languages: [python, sql, javascript]
```

- `languages` を書かなければ、`questions/` にある言語すべてを、名前順で使います
- `languages` に書いた順に、1日ずつ交代で出題されます（割合を変えるときは、README の「言語の選び方」を見てください）

### 4. 動かして確かめる

- `python drill.py` で、足した問題が出ることを確かめます。言語を指定して試すだけなら `python drill.py questions/javascript/u01_variables.yaml` です（記録は付きません）
- 問題集を足したあとは、`python run_tests.py` で、全体の試験が通ることも確かめてください

## 注意

- AI が作った問題は、正しいとは限りません。答えと解説は、自分でも確かめてください
- 自作の問題集を Git に上げるかどうかは、各自で決めます。上げたくないものは、`.gitignore` に `questions/{言語}/` のように書き足します
- 個人情報や、仕事・学校の内部の情報を、AI に貼り付けないでください
